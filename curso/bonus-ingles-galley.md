# Bonus — Inglés de galley

**Objetivo:** que el alumno tenga el vocabulario y las frases que va a usar todos los días a bordo.

## Lección B.1 — Vocabulario del barco (15 min)
| Inglés | Español |
|---|---|
| Galley | Cocina del barco |
| Crew mess | Comedor de tripulación |
| Bow / stern | Proa / popa |
| Port / starboard | Babor / estribor |
| Aft deck / sun deck | Cubierta de popa / solárium |
| Provisioning | Aprovisionamiento |
| Charter / owner trip | Chárter / viaje del dueño |
| Preference sheet | Hoja de preferencias |
| Shore leave | Día libre en tierra |
| Yard period / refit | Período en astillero |
| Rotation | Rotación |
| Daywork | Trabajo por día |
| Chief stew | Jefa/e de interior |
| Tender | Lancha auxiliar |

## Lección B.2 — Frases con huéspedes y tripulación (15 min)
- *Good morning, what would you like for breakfast today?*
- *Do you have any allergies or dietary requirements?*
- *Tonight I've prepared a four-course Mediterranean menu.*
- *Lunch will be served on the aft deck at 1 pm.*
- *Could you let me know the guests' arrival time?* (al chief stew)
- *We're running low on fresh produce; I'd like to provision in the next port.* (al capitán)
- *Crew lunch is ready!*

## Lección B.3 — Inglés para la entrevista (10 min)
- Presentación de 30 segundos (plantilla para memorizar y adaptar).
- Respuestas modelo a las 5 preguntas del Módulo 5.
- Cómo pedir que te repitan sin ponerte nervioso: *Sorry, could you say that again?*

**Descargable:** glosario completo imprimible.
